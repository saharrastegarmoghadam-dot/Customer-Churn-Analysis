# 📌 Customer Churn Analysis Project

## 📊 Project Overview

This project analyzes customer churn data from a telecommunications company to understand why customers leave and identify patterns in customer behavior.

The goal is to explore churn trends using Python and data visualization techniques.

---

## 🧠 Key Insights

- Around **26.5% of customers churned**
- Majority of customers (**73.5%**) stayed
- Churn behavior is analyzed using:
  - Customer count
  - Percentage distribution
  - Visual chart analysis

---

## 📂 Dataset

The dataset used is the **Telco Customer Churn dataset**, which contains customer demographic information, account details, and churn status.

Source: Kaggle (Telco Customer Churn)

---

## 🛠️ Tools & Technologies

- Python 🐍
- Pandas 📊
- Matplotlib 📈
- Seaborn 🎨

---

## 📊 Features

✔ Load and analyze dataset  
✔ Calculate churn count and percentage  
✔ Identify customer churn patterns  
✔ Visualize churn distribution using bar chart  

---

## 📈 Visualization

The project includes a bar chart showing:

- Customers who stayed (No)
- Customers who left (Yes)
